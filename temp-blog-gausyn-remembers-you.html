Gausyn remembers you, and you can make it forget

The Gausyn team · October 2026 · 1 min read

A teacher who knows you does not start from zero each time. They remember that you like a picture before the algebra, and which step tripped you up last week. That memory is a large part of why good teaching works.

So Gausyn now keeps a few short notes as you learn together: how you like things explained, and what tripped you up last time. The next lesson starts from there rather than from the beginning.

Yours to read

Memory only feels right if you can see it. You can read every note in Settings, and you can forget any one of them, or all of them. They are short on purpose, and they are written so that you can understand them.

Plain about what it is

The same thinking applies to honesty. A program that remembers you and speaks to you can start to feel like something else, so we made sure it never pretends. Ask Gausyn whether it is a real person and it says plainly that it is not: it is a computer program that teaches.
